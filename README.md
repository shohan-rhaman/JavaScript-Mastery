| Method               | Purpose                        |
| -------------------- | ------------------------------ |
| `querySelector()`    | Get one element                |
| `querySelectorAll()` | Get multiple elements          |
| `textContent`        | Read or change text            |
| `classList`          | Add/remove/toggle classes      |
| `dataset`            | Read custom data attributes    |
| `createElement()`    | Create a new element           |
| `appendChild()`      | Add an element to the DOM      |
| `remove()`           | Remove an element from the DOM |
